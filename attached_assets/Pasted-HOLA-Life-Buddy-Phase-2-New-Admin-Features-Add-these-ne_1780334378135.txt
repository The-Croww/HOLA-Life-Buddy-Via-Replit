HOLA! Life Buddy — Phase 2: New Admin Features

Add these new features to the ADMIN WEB DASHBOARD at artifacts/web-admin/ AND the admin mobile app at artifacts/mobile-admin/

FEATURE 1 — AI CLIENT SUMMARY
On the Client Profile page (web + mobile admin):
- Add an "AI Summary" button next to the client name
- Clicking it calls the backend which sends the client's last 14 mood entries, top emotions, and completed tasks to Groq API
- Groq generates a 3-4 sentence clinical summary: mood pattern, emotional themes, engagement level, suggested focus areas
- Display in a card with a "Generated by AI" badge and timestamp
- Backend: POST /api/v1/psychologist/clients/:id/ai-summary
- Cache the summary for 24 hours (don't regenerate on every click)

FEATURE 2 — SESSION NOTES WITH TEMPLATES
Enhance the Notes tab on Client Profile:
- Replace plain textarea with a structured note editor
- Template selector: SOAP Note / Free text / Progress note
- SOAP template: Subjective / Objective / Assessment / Plan (4 separate fields)
- Progress template: Session goals / What was covered / Homework assigned / Next session focus
- Save notes to backend: POST /api/v1/psychologist/clients/:id/notes
- Notes history: list of past saved notes with date, clickable to view
- Backend: add notes storage to the in-memory store

FEATURE 3 — TREATMENT GOALS TRACKER
New section on Client Profile — "Goals" tab (5th tab):
- Psychologist sets treatment goals for the client: title + description + target date + status (active/achieved/paused)
- Goal list with progress indicator
- Mark goal as achieved → celebration animation
- Goals visible to client in their mobile app under Profile (read-only)
- Backend: POST/GET/PATCH /api/v1/psychologist/clients/:id/goals

FEATURE 4 — WEEKLY REPORT EMAIL PREVIEW
New page in web admin: "Reports" (add to sidebar under Insights)
- Weekly summary card per client: avg mood, check-in rate, tasks completed, top emotions, AI insight sentence
- "Preview report" button shows a formatted report card
- "Export PDF" button (use browser print dialog for MVP)
- Date range selector: this week / last week / last 30 days
- Practice overview: total check-ins across all clients, most improved client, avg mood trend

FEATURE 5 — APPOINTMENT SCHEDULER (MVP)
New section in web admin sidebar: "Schedule"
- Simple calendar view (weekly grid)
- Create appointment: client selector, date/time picker, session type (Initial / Follow-up / Crisis), notes
- Appointments stored in backend: POST/GET /api/v1/psychologist/appointments
- Client sees their upcoming appointment in their mobile app Home screen
- Reminder card 24 hours before appointment on both admin and user app

Apply all new features to the admin mobile app as well — same data, mobile-optimized layout.
