FEATURE 2 — INTERACTIVE CBT TOOLS (replace "coming soon" in Mindfulness tools tab)
Build each tool as a full interactive screen:

Tool A — Worry Box
- User types a worry into a text field
- Taps "Lock it away" → worry animates into a box with a satisfying close animation
- Stored locally in AsyncStorage
- Can view/delete locked worries

Tool B — Gratitude Jar
- User writes one thing they're grateful for
- Taps "Add to jar" → item drops into an animated jar (SVG or emoji)
- Shows count: "You have X things to be grateful for"
- Stored locally, list view available

Tool C — Thought Reframe (CBT)
- 3-step flow: 1) Write the negative thought, 2) Identify the cognitive distortion (tap from list: catastrophizing, mind reading, all-or-nothing, etc.), 3) Write a reframed thought
- AI assists step 3: "Help me reframe" sends the thought to Groq and suggests a balanced alternative
- Saves completed reframes to history

Tool D — 5-4-3-2-1 Grounding
- Guided interactive exercise: tap to reveal each sense category
- 5 things you can SEE → 4 HEAR → 3 TOUCH → 2 SMELL → 1 TASTE
- Each has a text input for the user to fill in
- Progress bar across top, completion celebration at end
